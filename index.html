Guardado automático en GitHub

El micrositio lee y escribe un único archivo JSON en tu repositorio. Los visitantes lo leen sin token; solo quien edita necesita uno.

Seguridad: el token se guarda únicamente en este navegador (localStorage) y nunca se escribe dentro del JSON ni del HTML. No lo pegues en el código ni lo subas al repo: GitHub lo revoca automáticamente si aparece en un commit. Usa un token fine-grained limitado a este repositorio con permiso Contents: Read and write y con fecha de expiración.
Se guarda local. Para quitarlo del navegador usa “Olvidar token”.
Cada guardado genera un commit, así queda historial y se puede revertir.

Imágenes y repositorio

Cada espacio de imagen tiene una clave. Define la URL base y el src se arma como base + clave. Si publicas en GitHub Pages, puedes usar una carpeta del propio repo, por ejemplo ./img/.

Con clave logo-guaca.png se cargará ./img/logo-guaca.png.
